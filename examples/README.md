# 演示导入数据

`demo-import.xlsx` 包含“商品”和“客户”两个工作表，全部为虚构资料。

在应用首页点击“导入商品与客户 Excel”，选择该文件，核对新增/更新数量后确认。与首次启动的演示数据编码相同，重复导入按编码更新。

- 商品：`产品编码`、`产品名称`为必需列；品牌、规格、整箱规格、单位和单价为可选列。
- 客户：`客户编码`、`客户名称`为必需列；收货地址、联系人和电话为可选列。
- 未提供的可选列保留现有值；明确提供空单元格则清空对应字段，单价空单元格按零处理。
- 演示文件没有真实电话、公司、客户资料或订单记录。请勿把实际导入文件、数据库或备份提交到仓库。
