# 工作台 UI · v1.3

目标：在常规桌面与较小窗口下保持紧凑、清晰的业务界面。

设计：深墨绿导航、暖白背景、少量琥珀色状态强调。页面共享导航、紧凑工具栏、对齐的数字和表头；详情按单据元信息、收发货双方、商品明细分组。空的可选字段默认收起，原始内容可展开查看。打印纸面毫米尺寸与业务规则保持一致。

实施：
1. 增加共享工作台导航和样式变量，覆盖订单、表单、商品/客户、汇总、生产库存及弹窗。
2. 重排单据详情；状态提示压缩为行内信息；列表添加带数量的状态快捷筛选。
3. 生成虚构数据截图检查常规和小窗口布局，运行原有流程与打印 PDF 测试。
4. 在临时用户目录中验证目录版打包后的完整流程。
