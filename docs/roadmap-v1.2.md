# v1.2 实施与验收

按用户授权顺序实施，保留原数据、应用标识和演示数据隔离。

1. 订单编辑：核心字段优先，运输与签收折叠；发货单位/电话/仓库/制单人默认值；复制订单生成新单号；离开未保存编辑时确认。验收默认值持久化、复制不复用单号/状态、取消不写订单。
2. 打印：每台打印机支持多套命名收藏；保存、应用、删除均验证配置且事务提交。独立校准页带尺寸边框和标尺，使用相同纸型、方向、边距，仅请求一份。验收收藏隔离与校准 PDF 尺寸及确认流程。
3. 历史快照：箱规写入订单明细，读取不再关联实时商品；升级只补齐一次现有箱规，无法还原升级前已丢失的旧值。验收商品修改后旧单不变。
4. 库存/状态：所有在用的库存操作改为主进程业务事务；库存数量、流水、生产状态一起提交。订单草稿→已确认→已发货；确认不扣库存，发货必须明确选择成品库存并原子扣减。已发货作废须确认退回并恢复原库存一次。未发货可退回草稿。禁止非草稿编辑/删除，保留状态审计。

旧订单标记为历史单据，不推断历史发货或倒扣库存，可查看、打印、复制为新草稿。旧备用 SQL 库存表保留归档并显示待核对提示，不凭名称猜测与生产库存的对应关系。现有生产库存记录原 ID 保留，作为在用库存唯一来源。

验证：真实临时 SQLite 回滚/重复发货/库存不足/作废/旧库升级测试，Electron UI 默认值与未保存确认、收藏与校准、快照与状态流测试，原项目与公开版同步测试、目录打包、脱敏检查及 GitHub CI。
